# KMP 字符串匹配程序

本程序使用 C++ 实现 KMP（Knuth–Morris–Pratt）字符串匹配算法，通过自定义 `String` 类构造模式串的失败函数，并返回模式串在主串中第一次出现的位置。

## 功能

- 构造失败函数，记录每个前缀的最长相等真前后缀长度。
- 使用 KMP 查找首次匹配位置，返回从 `0` 开始的下标。
- 找不到模式串时返回 `-1`。
- 区分大小写，空格和标点按普通字符参与匹配。
- 空模式串返回 `0`；空主串匹配非空模式串返回 `-1`。

## 编译与运行

需要支持 C++11 或更高版本的编译器。将 `String` 类和下方示例 `main()` 放入同一个源文件 `main.cpp`，并在文件开头加入：

```cpp
#include <cstring>
#include <iostream>
```

类中使用的 `strlen`、`strcpy` 可分别写成 `std::strlen`、`std::strcpy`。

使用 GCC 编译并运行：

```bash
g++ -std=c++11 -Wall -Wextra main.cpp -o kmp
./kmp
```

本 README 不附带独立的 `main.cpp`，源文件需要使用上述方式组合。

## 使用示例

```cpp
int main()
{
    String text("ABABABAC");
    String pattern("ABABAC");

    std::cout << "首次匹配下标："
              << text.KMPfind(pattern) << '\n';

    std::cout << "失败函数：";
    for (int i = 0; i < pattern.len; ++i)
        std::cout << pattern.f[i] << ' ';
    std::cout << '\n';

    return 0;
}
```

预期输出：

```text
首次匹配下标：2
失败函数：0 0 1 2 3 0
```

## 类与接口

| 成员或方法 | 说明 |
|---|---|
| `char *str` | 字符缓冲区；默认构造时为 `nullptr` |
| `int len` | 字符串长度，不包含结尾的空字符 |
| `int *f` | 失败函数数组；调用 `failure()` 后才有有效内容 |
| `String(const char *s = nullptr)` | 复制以空字符结尾的输入字符串；默认构造为空串 |
| `~String()` | 释放字符缓冲区和失败函数数组 |
| `void failure()` | 为当前字符串计算失败函数 |
| `int KMPfind(String &pat)` | 在当前对象中查找 `pat`，返回首次匹配下标或 `-1` |

调用形式：

```cpp
int position = text.KMPfind(pattern);
```

`KMPfind()` 会调用 `pattern.failure()`，因此会更新模式串的 `f` 数组。

## 失败函数原理

`f[i]` 表示子串 `str[0...i]` 中最长相等真前缀和真后缀的长度。真前缀、真后缀不包含整个子串；不存在非空匹配时，长度为 `0`。

以模式串 `ABABAC` 为例：

| i | 子串 | 最长相等真前后缀 | f[i] |
|---:|---|---|---:|
| 0 | A | 无 | 0 |
| 1 | AB | 无 | 0 |
| 2 | ABA | A | 1 |
| 3 | ABAB | AB | 2 |
| 4 | ABABA | ABA | 3 |
| 5 | ABABAC | 无 | 0 |

构造失败函数时，先令 `k = f[i - 1]`，尝试在原有相等前后缀后增加新字符。若 `str[i] != str[k]`，则执行：

```cpp
k = f[k - 1];
```

这会跳到更短的候选前后缀长度，而不是简单地将长度减一。若新字符匹配成功，则 `k++`，最后保存 `f[i] = k`。

空串必须在访问 `f[0]` 前返回：

```cpp
if (len == 0)
    return;
```

## KMP 查找原理

`i` 是主串当前比较的位置，`j` 是模式串当前比较的位置，同时表示已经匹配的字符数。

1. 字符相同：同时增加 `i` 和 `j`。
2. 字符不同且 `j == 0`：增加 `i`，尝试主串下一位置。
3. 字符不同且 `j > 0`：令 `j = pat.f[j - 1]`，保持 `i` 不变。
4. 当 `j == patLen` 时，匹配完成，返回 `i - patLen`。
5. 主串扫描结束而模式串未完全匹配时，返回 `-1`。

例如主串为 `ABABABAC`、模式串为 `ABABAC`：匹配了 `ABABA` 后，主串的 `B` 与模式串的 `C` 不同，此时 `i = 5`、`j = 5`。执行 `j = f[4] = 3` 后，已经匹配的后缀 `ABA` 可以继续利用，再比较当前位置的 `B`。最终在下标 `2` 找到模式串。

## 复杂度

设主串长度为 `n`，模式串长度为 `m`：

| 操作 | 时间复杂度 |
|---|---|
| 构造失败函数 | O(m) |
| 扫描主串 | O(n) |
| 一次完整的 KMPfind 调用 | O(n + m) |

失败函数需要 `O(m)` 空间。当前类还会复制输入字符串，并为每个对象分配失败函数数组，因此主串和模式串两个对象总共占用 `O(n + m)` 存储空间。查找过程本身只使用常数个局部变量。

## 使用限制与改进方向

- **对象复制与赋值**：当前类使用裸指针，默认复制会共享同一块内存，可能导致重复释放；默认赋值还可能造成内存泄漏。当前版本应避免按值复制、赋值。可实现深拷贝，或删除复制构造与复制赋值操作。
- **公开成员**：直接修改 `str`、`len` 或 `f` 可能破坏对象的一致性。可将其设为私有成员并提供受控接口。
- **重复预处理**：每次查找都会重新计算模式串的失败函数。同一模式串多次查找时，可考虑缓存，并在模式串改变后重新计算。
- **字符表示**：匹配按 `char` 字节进行，返回的是字节下标；UTF-8 中文等多字节文本的字节下标不等于字符序号。
- **输入格式**：构造函数依赖 `strlen`，不支持字符串内部包含空字符 `\0` 的二进制数据。长度使用 `int`，不适合超出其表示范围的超大输入。
- **查找范围**：目前只返回首次匹配位置；查找所有匹配位置需要扩展接口和匹配完成后的处理。

可使用 `std::string` 与 `std::vector<int>` 改进内存管理，同时保持现有 KMP 算法逻辑。
